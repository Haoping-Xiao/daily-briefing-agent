读取 inputs/profile.json、calendar.json、emails.json、news.json。

硬约束
最容易扣分的约束是这些：

输出简报必须是 英文，不是中文。
briefing.txt 不能有 Markdown、URL、邮箱地址。
数字和单位要口语化：比如 four billion dollars，不是 $4B。
控制在 60–90 秒，目标 75 秒。实际大概就是 180–210 个英文词左右。
不能伪造输入，最终输出必须基于原始 inputs/。
API key 如果用外部模型，必须走环境变量。
private / sensitive 信息不能泄露。
开头不能每天都 Good morning。
DECISIONS.md 里要诚实写取舍，不要假装全自动完美。
